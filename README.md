# andremarinho.me

Personal site built with Next.js, TypeScript, Tailwind CSS, and Markdown.

## Development

```bash
pnpm install
pnpm dev
```

Run `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build` before shipping.

Lighthouse runs against the production build on pull requests.

## Content

Posts, project cases, and the professional overview for `/llms.txt` live in
`content/`. See [the content guide](content/README.md) for frontmatter,
publication rules, project relationships, and public Markdown URLs.
